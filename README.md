# 原稿進捗管理ツール

## 📝 概要
同人活動・創作作業向けに設計された、個人用の原稿進捗管理ツールです。  
Django製Webアプリとして、プロジェクトの進捗管理・目標ノルマ計算・カレンダー表示などを備えています。
ほぼ自分が欲しい機能だけが入っている状態なので、必要な機能ありましたら適宜追加どうぞ。

## ⚙ 主な機能

- 原稿プロジェクトの登録（タイトル・総ページ数・締切・1日あたり作業可能時間など）
- 日々の進捗入力（ページ数・日付）
- 自動ノルマ算出（「今日描くべきページ数」を自動提示、切り上げ・実数・自由入力で登録可）
- 進捗バー表示（トップ・詳細画面どちらにもミニバー付き）
- カレンダー形式での進捗可視化（✅アイコン表示、プロジェクトカラー反映）
- プロジェクトの編集／削除機能、進捗の削除機能あり
- モバイル表示対応（レスポンシブCSS）

## 🛠 使用技術

- Python 3.9
- Django 4.2
- HTML/CSS（組み込みスタイル）
- SQLite（DjangoデフォルトDB）

## 📦 セットアップ方法

1. リポジトリをクローン：

```bash
git clone https://github.com/your-username/progress-tracker.git
cd progress-tracker
```
２．仮想環境を作成・起動：
```bash
python3 -m venv myenv
source myenv/bin/activate
```
３．依存パッケージをインストール：
```bash
pip install django
```
４．サーバー起動：
```bash
python manage.py runserver
```
